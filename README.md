# 這裡完全是一個小遊戲開發分支。

- 呈現簡單的直式加法給小朋友練習。

- 分成兩個部分
  - 練習模式 -> 簡單先實作
  - 動畫演示 -> 慢慢計畫

- 基本--可以選擇幾個數字相加 --> 2~4個數字

- 基本--可以選擇幾位數 --> 1~5位數 顯示個/十/百/千/萬/十萬

- 基本--可以選擇是否包含減法 (過多數字練習強度過高，不建議)
  - --> 減法 2個數字 -> (A-B)
  - --> 減法 3個數字 -> (A+B-C)

- 進階--可以選擇是否包含負數

- 進階--可以選擇是否包含小數點 -> 小數點要幾位

# 跟其他專案的相容方式

## 遊戲本體必須是component + service

- 遊戲本體透過 <router-outlet /> 顯示
- 將component和service 放到 src/app/plusingGame/ 內->搬運到主網站後，透過路由顯示即可搬運
- 其他網頁本體設定暫時根本無所謂。(雖然姑且改一下manifest了)

## 遊戲規則

用中文解釋小朋友才好懂

1. 每個關卡有輸入和輸出，邏輯閘透過按鈕控制輸入，輸出會顯示在燈泡上(0->1)
   這一點都不好玩!
   要用可愛的水果，問問老闆有沒有，老闆在刁難的問客人零錢夠不夠!
   範例:「請問老闆，你有沒有賣蘋果或香蕉呢？」　or邏輯
   「一共60元，請問小朋友，你的零錢有沒有50元和10元呢？」 and邏輯
   「請問老闆，你沒有賣蘋果，對嗎？」 not邏輯
   「請問小朋友，你沒有50元，也沒有100元，對嗎？」 xor邏輯
   剩下蘋果和香蕉的時候：隔壁先來的客人說他要買蘋果或香蕉，那你想要買蘋果和香蕉的話，你是缺了蘋果和香蕉嗎？　(nand)
2. 每個關卡有邏輯閘，邏輯閘有AND, OR, NOT, XOR, NAND, NOR
